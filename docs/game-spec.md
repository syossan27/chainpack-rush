**技術**: TypeScript ＋ Phaser 3（描画）＋ Vite ＋ Capacitor ＋ Vitest。ゲームのルール（`src/core`）は Phaser に依存しない純粋なロジックで、1/60 秒の固定ステップ・シード付き乱数で動く。同じシード・同じ配置・同じ操作なら必ず同じ結果になる（ランキングでサーバーがランを再生して検証するため）。セーブは端末内のみ（Capacitor Preferences / ブラウザの保存領域）。ランキング用に Firebase（匿名ログイン・Firestore・Cloud Functions）のコードがあるが未稼働。

### 1.1 遊びの流れ

1. **拠点**で「出撃」→ **地域を選ぶ** →「出撃！」
2. **ラン**: 勇者が走り、敵に接すると足元のゲージ（攻撃間隔）がたまるたびに、盤面の起点石から連鎖が発火して装備が順に攻撃する（重ねた装備は下から順に）。ボスを倒すとレリックを1つ選んで盤面のマスに貼り、次の周回へ。時間切れ・力尽きる・撤退で終わる
3. **結果**: 拾った戦利品（宝箱）・ゴールド・アクセサリーを持ち帰る（力尽きても没収なし）。攻撃した属性の熟練が伸びる
4. **拠点**で、倉庫の整理・鍛冶屋（出口の付け直し・合成）・永続強化・**配置**（並べ替え・重ね・盤面の切り替え・アクセサリーの付け替え）をして、また出撃
5. 地域を進めると次の地域が開き、新しい盤面がもらえる。最後の地域のボス（魔王）を倒すとエンドレス。2週替わりの挑戦とランキング（未稼働）もある

最初の出撃は「体験ラン」（伝説の装備を重ねた盤面を借りた20秒のラン）で、終盤の姿を先に見せる（11.8）。

## 3. ゲームの核: 盤面と連鎖

### 3.1 盤面

- 装備を並べるマス目。種類ごとに形（穴のあるもの）と特徴がある（6.1）。最初は「標準の盤面」（4×3、穴なし）だけ。穴のマスには何も置けない。
- 1マスに**同じ装備**（同じ種類なら、レアリティは問わない）を**3つまで重ねられる**（深い盤面は4つ）。違う装備は重ねられない。起点石とアーティファクトは重ねられない（1マスに1つ）。
- 起点石は**盤面に1つだけ**。起点石が置かれていないと出撃できない。
- 消耗品はマスに置けず、別の「消耗品枠」（初期3、最大5）に入れる。消耗品枠は盤面ではなくプレイヤーについてくる（盤面を切り替えても同じ）。

### 3.2 装備の種類

| 種類                   | 役割                                                                                                                                                                   | 連鎖数               |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| 起点石（Origin Stone） | 連鎖の始まり。攻撃しない。盤面に1つ、重ねられない。レアリティ＝出口の数（コモン1・レア2・エピック3・レジェンド4）。種類つきの起点石は、連鎖の装備に効果を与える（5章） | 数えない             |
| 攻撃装備               | 発動すると敵を攻撃する。属性・攻撃範囲・攻撃力（ATK）を持つ                                                                                                            | 1つ数える            |
| 防御装備               | 発動しても攻撃しない。連鎖が終わったとき防御値を加える                                                                                                                 | 数えない（通すだけ） |
| アーティファクト       | ごくまれに出る特別な装備（攻撃5種・防御1種）。常にレジェンド、出口の形が固定、追加効果なし。重ねられないが、1つでマスの深さの回数（3回、深い盤面は4回）鳴る            | 種類どおり           |
| 消耗品                 | ラン中にタップして使う（8種）。マスには置けない                                                                                                                        | —                    |

### 3.3 連鎖の伝わり方

- 起点が発火すると、起点の**出口の向きの隣のマス**へ連鎖が伝わる。伝わったマスの装備が発動し、さらにその装備の出口の先へ伝わる。
- **重ねたマス**は、**下から順に**1つずつ鳴る（間は **0.1秒**）。全部鳴ったあと、**一番上の装備の出口**の先へ伝わる（下の装備の出口は使わない）。
- **入口の制約はない**: 隣から出口が向いていれば、どの面からでも受け取る。
- 出口が盤外・穴・空きマスを向いていれば何も起きない。出口0の装備はそこで線が終わる（末端）。
- 出口が複数あれば**枝分かれ**して同時に進む。
- 1回の発火で、各マスは**1回だけ**鳴る（重ねは全部鳴る）。すでに鳴ったマスへは戻らない（輪になっても止まる）。
- 同時に届いた場合は、先に発動した親が優先、同じ親なら出口の上→右→下→左の順。
- 次のマスへ伝わるまでの時間（伝達）は、そのマスの**一番上の装備**の値で **0.2秒**。装備ごとに違うものがある（大剣・大斧・大盾 0.4秒、鋼の鎧 0.3秒、短剣・革鎧・疾風の羽 0.1秒）。起点石の種類（速・重い）で ±0.05秒。最短 0.05秒。
- 連鎖の長さ（持続時間）＝最後の装備が鳴った時刻 ＋ 0.2秒。
- 起点から届かない装備は配置画面で灰色になる（戦闘では発動しない）。

### 3.4 連鎖数・連鎖倍率・重ねの倍率

- 起点から数えて、**攻撃装備が鳴るたびに連鎖数が1増える**。重ねた攻撃装備は1つずつ数える（3つ重ねなら連鎖数が3進む）。防御装備・起点石は数えない（受け取った数をそのまま渡す）。標準の盤面では、起点のマスを除く11マス×3つで最大33連鎖（疾風の羽などの上乗せを除く）。
- 疾風の羽: この羽の**あとに続く**装備の連鎖数を、さらに +1 多く数える（羽自身はふつうに数える）。例: 起点→疾風の羽（1）→剣（3）→剣（4）。
- **連鎖倍率 = 1.2^(連鎖数−1)、上限 ×2.5**（6連鎖目で ×2.49、7連鎖目から ×2.5）。
- その発火のルートのどこかに「循環の環」（アーティファクト）があれば、その発火全体の上限が **×4.0**（9連鎖目で到達）。

| 連鎖数           | 1    | 2    | 3    | 4    | 5    | 6    | 7    | 8    | 9以降 |
| ---------------- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ----- |
| 倍率（通常）     | 1.00 | 1.20 | 1.44 | 1.73 | 2.07 | 2.49 | 2.50 | 2.50 | 2.50  |
| 倍率（循環の環） | 1.00 | 1.20 | 1.44 | 1.73 | 2.07 | 2.49 | 2.99 | 3.58 | 4.00  |

- **重ねの倍率**: 重ねの**下から何番目か**で、ダメージと防御値に倍率がかかる（連鎖倍率とは別）。

| 下から   | 1つ目 | 2つ目 | 3つ目 | 4つ目 |
| -------- | ----- | ----- | ----- | ----- |
| ふつう   | ×1    | ×1.5  | ×2    | —     |
| 深い盤面 | ×1    | ×1.25 | ×1.5  | ×2    |

- 倍率は位置で決まる。1つだけのマスは ×1、2つ重ねの一番上は ×1.5。アーティファクトは1つで深さの回数鳴り、各回にこの倍率がかかる。
- **敵を倒しても連鎖数は続く**: 狙っていた敵が倒れると、その枝は次の敵へ移り、連鎖数をそのまま数え続ける（すべてのランの種類で。8.3）。記録（最大連鎖）や追加効果「先駆け」「締め」は、戦闘での実際の連鎖数で判定する（レリック「加速の羽」の分も入る）。

### 3.5 発火と攻撃間隔

- 起点は盤面に1つなので、ゲージがたまるたびに同じ起点が発火する。
- 勇者の足元のゲージ（攻撃間隔、初期1.5秒。疾風の盤面では ×0.7）は、連鎖していない間たまる（走っている間もたまる）。満タンかつ敵が目の前の立ち位置まで来ていると発火する。
- 連鎖が終わったあとの次の待ちは、**その発火で鳴ったマスの数（起点を除く。重ねたマスは1つと数える。防御装備のマスも数える）に比例**する（7.1）。

### 3.6 例

標準の盤面（4×3）の初期配置（初期セーブ）:

```
行0: [      ] [      ] [      ] [        ]
行1: [起点→] [剣×2→] [斧→  ] [木の盾→]
行2: [      ] [      ] [      ] [        ]
```

- 発火: 剣（下。1連鎖・連鎖 ×1.0・重ね ×1）→ 0.1秒後に剣（上。2連鎖・×1.2・重ね ×1.5）→ 斧（3連鎖・×1.44・重ね ×1、薙ぎ払い）→ 木の盾（数えない。連鎖終了時に防御値 +8）。
- 鳴ったマスは3つ（剣の重ねは1つと数える）なので、次の待ちは 1.5秒 × 3/6 = 0.75秒。

## 4. ダメージ

### 4.1 ダメージ式（攻撃1回・敵1体あたり）

```
ダメージ = ATK × レアリティ倍率 × 連鎖倍率 × (コンボ倍率 or 状態×1.2 or 1)
         × 攻撃倍率（強化＋★） × (全体攻撃なら ×0.4)
         × 揺れ(±10%) × 会心(×2) × 必殺技(×2.5)
         × 重ねの倍率 × 起点石の種類のダメージ補正
         × 敵の属性倍率（得意・苦手） × 地域の効きにくい属性(×0.7)
         × 追加効果の倍率 × 熟練(1 + 0.03×Lv) × 盤面の特徴
         × レリック「巨人の拳」(×2.5) × アクセサリーのコンボ倍率（上限×20）
```

- レアリティ倍率: コモン ×1.0、レア ×1.5、エピック ×2.5、レジェンド ×4.0（防御値にも掛かる）。
- 攻撃倍率: 1 ＋ 0.05×（強化「攻撃倍率」の段）＋ 0.03×（★の数）。
- 状態が付いている敵へのコンボ以外の攻撃は ×1.2（状態の種類は問わない）。コンボが起きたときはコンボ倍率だけ（×1.2 は重ならない）。
- 重ねの倍率は 3.4。盤面の特徴は 6.1、地域の効きにくい属性は 4.5、熟練は 4.8、レリックは 8.10、アクセサリーのコンボ倍率は 6.3。
- 追加効果の倍率: 鋭い・先駆け（連鎖数3以下）・締め（連鎖数6以上）・弱点突き（状態の付いた敵）・ボス特効（ボス）・初撃（連鎖数1、その発火の起点石の効果）を掛け合わせる。竜牙の剣のボス ×2 もここ。
- 攻撃範囲が複数体のときは、当たった敵ごとに計算する。双剣は1回の発動で2回攻撃（連鎖数は1つ）。
- 結果は0.01単位に丸める。攻撃力0の装備はない（最低は雨雲の杖の ATK 2）。

### 4.2 会心と揺れ

- 会心率 8%（攻撃1回ごとに抽選。範囲攻撃なら当たった全員が会心、双剣は2回それぞれ抽選）、会心ダメージ ×2。
- 会心率を上げるもの: 聖剣 +20%、追加効果「会心」+3〜10%、消耗品「幸運の硬貨」+30%（8秒）、レリック「会心の眼」+50%。
- ダメージは ±10% 揺れる。

### 4.3 状態とコンボ

- 状態は付けた攻撃のダメージの**あと**に付く（同じ攻撃で付けて消費はしない）。持続5秒（付け直すと5秒に戻る）。
- コンボは状態を**消費**する。判定は当たった敵ごと。

| 状態（付ける装備）                     | 当てる属性 | コンボ | 倍率 | 追加効果                                                          |
| -------------------------------------- | ---------- | ------ | ---- | ----------------------------------------------------------------- |
| 濡れ（水竜の瓶・雨雲の杖・雨乞いの符） | 雷         | 感電   | ×3   | —                                                                 |
| 油（油瓶・油の大樽）                   | 炎         | 爆発   | ×2   | 単体攻撃が範囲攻撃に広がる（狙いが油まみれのとき）                |
| 凍結（氷の剣・氷の杖）                 | 打撃       | 粉砕   | ×2.5 | 「一撃○○未満を無効」の敵の守りを5秒崩す。凍結は敵の行動を止めない |
| 呪縛（闇の剣・闇の杖）                 | 光         | 浄化   | ×1.5 | 勇者のHPを最大HPの1%回復                                          |
| 灼光（光の剣・太陽の杖）               | 闇         | 封印   | ×1.5 | 敵の攻撃のたまり方が4秒間 ×0.7                                    |

- 光は灼光を、闇は呪縛を付けるので、**光と闇を交互につなぐと毎回コンボ**になる。
- 呪縛が付いている敵の攻撃力は −20%。
- 賢者の石（アーティファクト）は濡れ・油・凍結をまとめて付ける。

### 4.4 毒と風

- 毒（毒の短剣・毒霧の杖・深淵の杯）: 当てた一撃のダメージの **30%を毎秒**、5秒間与える。重ねがけは毎秒ダメージの強い方を残す。毒も「状態」なので、ほかの攻撃は ×1.2。
- 風（風の剣・嵐の杖）を毒の敵に当てると、毒が **1重ふえる**（毎秒ダメージ×重ね数、時間も5秒に戻る。最大5重）。**5重の敵**に当てると、残りの毒（毎秒×重ね数×残り秒）×1.5 をまとめて与えて毒が消える（**毒爆**）。毒のない敵にはふつうの攻撃。
- 毒の継続ダメージと毒爆は、「一撃○○未満を無効」の判定を受けない（コード上そうなっている）。

### 4.5 敵の属性の得意・苦手と、地域の効きにくい属性

- 敵ごとに属性別のダメージ倍率がある（書いていない属性は ×1）。火山・氷河・魔王城の敵が持つ（14章）。属性は 物理・打撃・炎・雷・氷・水・油・風・光・闇 の10種。
- それとは別に、**地域ごとに効きにくい属性**が1つある（その地域の敵みんなに ×0.7。敵の倍率に重ねてかかる）: 洞窟は闇、城壁は雷、火山は風、氷河は光。草原・魔王城・エンドレスにはない。同じ敵がほかの地域にも出るので、敵ではなく地域の決まりにしている。カカシにはかからない。

### 4.6 必殺技（Special Move）

- 連鎖のルートで、**続く3つのマスの一番上の装備**が決まった並びになっていると、3つ目のマスの一番上の一撃が必殺技（ダメージ ×2.5）。間に別のマス（防御装備も）が入ると成立しない。重ねの下の装備は並びに関係しない。
- **使えるのは覚えた技だけ**（4.8）。普通のランとエンドレスでは、まだ覚えていない技の並びは、閃いたときだけ技になり、そのまま覚える。挑戦と体験ランでは、覚えていなくても全部の技が出る（覚えはしない）。カカシでは覚えた技だけ出る。

### 4.8 熟練と閃き

勇者は属性ごとに熟練を持つ（10属性）。必殺技は、はじめは使えず、ランの中で「閃いた」ときだけ覚える。

- **熟練がたまる**: 普通のランとエンドレスで、攻撃装備が1回鳴るたびに、その装備の属性に1たまる（属性のない装備は物理）。重ねた装備は1つずつ、アーティファクトは鳴った回数だけ数える。ランの結果で足す。
- **Lv**: Lv n に必要な合計は 50 × n(n+1)/2（Lv1 50、Lv2 150、Lv3 300…）。上限 **Lv30**（合計 23,250。それ以上たまっても変わらない）。
- **ダメージ**: Lv1 ごとに、その属性の装備のダメージ +3%（Lv30 で +90%）。
- **閃き**: まだ覚えていない必殺技の並び（4.6）が鳴ったとき、**技の属性の Lv × 15%**（上限100%）で閃く。閃くとその一撃が必殺技になり、その技をずっと覚える（「閃いた！」の帯）。閃かなければふつうの攻撃。Lv0 の属性の技は閃かない。技の属性は、クリムゾン・バーストが炎、トライ・サンダーが雷、フロスト・ブレイカーが氷、ほかの3つが物理。
- 覚えた技は、図鑑・配置画面の技名・実績「必殺技」（10.8）の数え方に使う。
- 挑戦と体験ランは熟練なし（Lv のダメージもなく、技は全部出る）。カカシは今の Lv と覚えた技だけを使い、閃かず、熟練もたまらない（1.2）。
- 結果画面に「熟練 物理 +○（Lv○↑）」のような伸びと、閃いた技が出る。

## 6. 盤面の種類とアクセサリー

### 6.1 盤面の種類

盤面は7種類。最初は標準の盤面だけで、ほかは**その地域を初めてクリアすると**もらえる（次の地域が開くこと。魔王城は3周目のボス＝魔王を倒すこと）。地域の盤面は、次の地域で役立つものにしている。もらうと結果画面に「新しい盤面！」が出る。

| 盤面       | 形（X＝マス、.＝穴）                       | マス | もらえる地域 | 特徴                                                       |
| ---------- | ------------------------------------------ | ---- | ------------ | ---------------------------------------------------------- |
| 標準の盤面 | 4×3（穴なし）                              | 12   | 最初から     | なし                                                       |
| 疾風の盤面 | 5×2（穴なし）                              | 10   | 草原         | 次の連鎖までの待ち ×0.7（ゲージの満タンが攻撃間隔 ×0.7）   |
| 小さな盤面 | 3×2（穴なし）                              | 6    | 洞窟         | ダメージ ×1.25                                             |
| 結晶の盤面 | `..X..` / `.XXX.` / `XXXXX` / `.XXX.`      | 12   | 城壁         | 氷と水の攻撃力 ×2                                          |
| 炎の盤面   | `..X.` / `.XX.` / `.XXX` / `XXXX`          | 10   | 火山         | 炎の攻撃力 ×2                                              |
| 稲妻の盤面 | `..XX` / `.XX.` / `XXXX` / `.XX.` / `XX..` | 12   | 氷河         | 雷の攻撃力 ×2                                              |
| 深い盤面   | 3×3（穴なし）                              | 9    | 魔王城       | 1マスに4つまで重ねられる（重ねの倍率 ×1・×1.25・×1.5・×2） |

- 「攻撃力 ×2」「ダメージ ×1.25」は、ダメージ式（4.1）の「盤面の特徴」として最後に掛かる。

### 6.2 盤面ごとの配置

- 盤面の種類ごとに配置を1つ覚えている（どのマスに何をどの順に重ねるか）。装備は倉庫に置いたままで、配置はそれを指しているだけ。
- 配置画面の上の ◀ ▶ で、持っている盤面を切り替える。出撃とカカシは今選んでいる盤面で行う（挑戦は別、9.5）。
- 初めて切り替えた盤面（覚えている配置がない）は、持ち物から自動配置で組む（11.4）。覚えている配置は、売った・使い切った装備を抜いて（下の装備が繰り上がる）今の持ち物に合わせる。
- 「装備中」は、今選んでいる盤面に置いた装備（重ねた下の装備も）と消耗品枠だけ。ほかの盤面の配置で使っている装備は倉庫に数え、一覧ではその盤面の名前の印（いくつもの盤面で使っていれば名前に「+」）が付く。今の盤面にも置ける（ほかの盤面の配置はそのまま）。
- ほかの盤面で使っている装備は、まとめて売る・一括売却・あふれた分を売る・合成の相方に入らない。詳細カードからは、確認のうえ売れる（その盤面から外れる）。
- 消耗品枠（と自動補充）は盤面ではなくプレイヤーについてくる。アクセサリーの枠は盤面ごと（6.3）。

### 6.3 アクセサリー

盤面のふちの枠に付けるもの。1回の連鎖の中で「コンボ倍率」を積み上げ、そのあとの攻撃のダメージに掛ける。

- **枠**: 列ごとに1つ、行ごとに1つ（その列・行に盤面のマスが1つもなければ枠はない）。標準の盤面は 4＋3 = 7枠。1枠に1つ。どの枠に何を付けたかは盤面ごとに覚える。
- **働き方**: 枠のアクセサリーは、**その列（行）のマス**で決まった出来事が起きるたびに、その連鎖のコンボ倍率を上げる（「+」は足し算、「×」は掛け算）。倍率は連鎖ごとに ×1 から始まり、上限は **×20**。上がった倍率は、そのあとの攻撃から効く（同じ攻撃の中では、攻撃を始めたときの倍率）。1つのマスの出来事には、列の枠が先、行の枠があとに働く。
- **種類**（6種。値はレアリティ別、コモン／レア／エピック／レジェンド。値は仮）:

| アクセサリー   | 計算 | 出来事（付けた列・行で）                                                                                           | 値                       |
| -------------- | ---- | ------------------------------------------------------------------------------------------------------------------ | ------------------------ |
| そろいの指輪   | +    | 攻撃装備のマスが撃つたび（重ねはマスの一番上で1回）。ただし、その列・行の攻撃装備が2つ以上で全部同じ属性のときだけ | 0.08 / 0.12 / 0.15 / 0.2 |
| 連鎖の首飾り   | ×    | 状態のコンボか毒爆が起きるたび（1回の攻撃で1回）                                                                   | 1.2 / 1.25 / 1.35 / 1.45 |
| 技の腕輪       | +    | 必殺技が出るたび                                                                                                   | 0.6 / 0.8 / 1 / 1.3      |
| 会心のピアス   | +    | 攻撃が会心になるたび（1回の攻撃で1回）                                                                             | 0.2 / 0.3 / 0.4 / 0.5    |
| とどめの髪飾り | ×    | 敵を倒すたび（1体ごと）                                                                                            | 1.06 / 1.1 / 1.15 / 1.2  |
| 重ねの護符     | +    | いっぱいの重ね（盤面の深さまで重ねたマス。アーティファクトも）の一番上が鳴るたび                                   | 0.05 / 0.08 / 0.1 / 0.12 |

- 連鎖の首飾りは、いちばん強いコンボ（感電 ×3）と毒爆では値どおり。弱いコンボでは上乗せ分（値−1）が（コンボの倍率−1）÷2 倍に減る（爆発は半分、粉砕は 3/4、浄化・封印は 1/4）。光と闇を交互につなぐと毎回コンボになるので、それだけで上限に張りつかないようにしている。
- **手に入れ方**: 敵が落とした装備1つごとに 1%（ボス・金ぴかの精鋭・黄金ゴブリンは 6%）で、アクセサリーも1つ落ちる。種類は6種から等確率、レアリティは装備と同じ決め方（10.2）。まだ1つも持っていない人は、最初のボスから必ず1つ落ちる。アクセサリーの抽選は別の乱数の流れなので、ほかの戦利品は変わらない。地域による出やすさの違いはない。
- 落ちるのは普通のランだけ。エンドレスでは付けて使えるが落ちない。挑戦・体験ランでは使わない。カカシでは付けたものが働く（1.2）。
- **アクセサリー入れ**: 30個まで。あふれた分は結果画面で売られる。売値: コモン10G・レア40G・エピック120G・レジェンド400G。どの盤面にも付けていないものは、詳細から売れる。倉庫の容量には数えない。
- 配置画面: 枠をタップして選ぶと、下の一覧がアクセサリー入れに替わり、タップで付ける。選んだ枠をもう一度タップすると外す。配置だけで条件を満たしている枠（そろいの指輪・重ねの護符）は光る。推定ダメージにはコンボ倍率が入る（会心ととどめは運と敵の体力しだいなので入れない）。
- ラン・カカシ: 盤面のふちに枠が出て、働くたびに光り、コンボ倍率が出る。

## 7. 短い連鎖と長い連鎖（待ち・守り・よろめき・防御値）

短い連鎖は回転が速く安全、長い連鎖は一撃が大きいが危険、という性格づけ（`CHAIN_RULES`）。

### 7.1 次の発火までの待ち

```
待ち = 攻撃間隔 × 盤面の待ち倍率 × clamp(鳴ったマスの数 ÷ 6, 0.25, 2.0) × (1 − 速攻%)
```

- 「鳴ったマスの数」は、その発火で実際に鳴ったマスから**起点を除いた数**（重ねたマスは1つと数える。攻撃装備のマスも防御装備のマスも数える。途中で打ち切られたら鳴った分だけ）。疾風の羽の +1 は関係しない。
- 盤面の待ち倍率は疾風の盤面だけ ×0.7（ほかは ×1）。
- 6マスでちょうど攻撃間隔1回分。最短 ×0.25。どの盤面もマスは12以下（起点を除くと11以下）なので、上限の ×2.0 には届かない。
- 例（攻撃間隔1.5秒・盤面 ×1）: 2マス → 0.5秒、6マス → 1.5秒、11マス → 2.75秒。
- レリック「呼び戻しの笛」のマスまで届いた連鎖のあとは、待ちが半分（8.10）。

### 7.2 無防備と守り

- 連鎖中は**無防備**: 被ダメージ ×1.5。
- ただし起点のあと、**3マス目が鳴るまで**は無防備にならない（守り）。数えるのは鳴ったマスの数（重ねたマスは1つ、防御装備のマスも含む）で、連鎖数ではない。
- アーティファクト「不落の城門」が盤面のどこかにあれば、連鎖中も無防備にならず、よろめかない（ルートにつながっていなくてもよい）。

### 7.3 よろめき

- 無防備の間に受けたダメージ（防御値で吸った分は除く）が、1回の連鎖の中で**最大HPの15%**に達すると「よろめき！」。残りの装備は発動せず連鎖が途切れる。

### 7.4 防御値

- 連鎖が終わったとき、その発火で通った防御装備の防御値の合計を勇者の「防御」に加える。防御値 = 基本値 × レアリティ倍率 ×（1+頑丈%）×（盾の起点石なら1.25）× 重ねの倍率。
- 防御は敵の攻撃を HP より先に吸収する。上限は最大HP。時間では減らない。
- 連鎖が途中で切れたときは、そこまでに通った防御装備の分だけ加わる。追加効果「癒し」は通った防御装備ごとに HP を回復。
- レリック「守りの札」のマスは、鳴るたびにすぐ防御 +5（8.10）。

## 8. 戦闘

### 8.1 フィールドと進行

- 横一次元のフィールド（距離は論理px）。勇者は右へ 160px/秒 で走る。
- 敵の群れの先頭が勇者の 300px 以内に入ると、**群れごと**勇者へ寄ってくる（240px/秒）。
- 勇者の前方 216px（交戦範囲）に敵がいると勇者は止まる。連鎖は、敵が勇者の前の立ち位置まで来て（接敵）からゲージ満タンで発火する。
- 群れは前後2列×横 80px 間隔で、立ち位置は勇者から 56 / 136 / 216px。前の列が倒れると後ろが詰める。
- 1周 = 地域ごとの数の雑魚の群れ → ボス。ボスを倒すと、その地点の 240px 先から次の周回が始まる。
- 画面内（全体攻撃・油の大樽などの対象）は勇者の前方 440px まで。

### 8.2 狙いと攻撃範囲

- **狙い**: 交戦範囲内の前列の敵のうち最も手前。後列の敵（呪術師・火の精・闇の魔導士）は、前列がいなくなるまで単体の狙いにならない。同じ位置ならボスより取り巻きが前。

| 範囲     | 当たる敵                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| 単体     | 狙いの1体（貫通 N の装備は、狙いの後ろ N 体にも同じダメージ。槍1・雷の槍1・弓2） |
| 薙ぎ払い | 交戦範囲（216px）内の全員                                                        |
| 範囲     | 狙いから ±80px 以内の全員                                                        |
| 全体     | 画面内（前方 440px）の全員。威力 ×0.4                                            |

### 8.3 連鎖中の狙いの切り替えと打ち切り

- 各枝は、親の装備と同じ敵を狙い続ける。**狙いが倒れていたら最も手前の敵へ移り、連鎖数はそのまま続く**（倍率も続きから）。すべてのランの種類で同じ（`runFeatures` の `keepCount`）。
- 攻撃の番に狙える敵が1体もいなければ、残りの装備は空振りせず**連鎖を打ち切る**（勇者はすぐ走り出し、ゲージもたまり始める）。
- 防御装備・起点石は、親の連鎖数と狙いをそのまま渡す。

### 8.4 敵の行動

- 近接の雑魚は最前列（勇者から 96px 以内）からだけ攻撃する。後列の雑魚とボスは交戦範囲のどこからでも攻撃する。
- 攻撃は攻撃間隔ごと。雑魚の最初の攻撃はシード乱数で最大50%早まる。
- 「時止め」中は敵が動かず攻撃せず、取り巻きの補充・ボスの能力も止まる（状態の残り時間と毒は進む）。

### 8.5 群れ・精鋭・ボス

- 群れの中身・数・間隔と、各周回のボスは**出撃ごとに抽選**（地域ごとの重み。9章）。前の周回と同じボスは避ける。
- 普通のランでは、群れの1つが黄金ゴブリンに替わることがある（8.11）。
- **精鋭**: 群れに1体まで混ざる。確率は1周目6%、周回ごとに +2%、上限20%（ボス・取り巻きはならない）。

| 精鋭   | 重み | HP   | 攻撃間隔 | 戦利品                    |
| ------ | ---- | ---- | -------- | ------------------------- |
| 硬い   | 4    | ×3   | ×1       | ふつう（ドロップ率で1個） |
| 速い   | 4    | ×1.5 | ×0.5     | ふつう                    |
| 金ぴか | 2    | ×2   | ×1       | 必ず2個、レア以上         |

- **ボスの能力**:

| 能力             | 内容                                                                                                                                        | 持つボス                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 取り巻きを呼ぶ   | ボスが寄ってき始めると決まった数をまとめて呼び、以後は数が減ると一定間隔で1体ずつ補充。取り巻きはゴールド・戦利品なし、ボスが倒れると逃げる | ゴブリン王・スライムの母・吸血女王・溶岩の巨人・氷の女王・魔王 |

- ボスは取り巻きがいる間は後ろ（216px）、いないと目の前（120px）に立つ。
- ボス接近時に「WARNING」の帯と「○周目のボス 名前」が出る（止めない）。

### 8.6 時間

- 基本 **30秒**（強化「出撃時間」で最大 +10秒）。**戦っている間（交戦中・連鎖中）だけ減る**。走っている間は止まる。
- 延長（上限なし）: ボス撃破 **+8秒**、一網打尽（群れの全員を同じ1回の連鎖で倒す。取り巻き・ボス・黄金ゴブリンは対象外）**+1.5秒**、消耗品「時の砂」**+5秒**、復活（広告）**+10秒**。
- レリックを選んでいる間（最大8秒）は、時間も敵も止まる（8.10）。
- 体験ランは延長なし。

### 8.7 勇者の能力値

| 能力     | 初期  | 増やす方法                   |
| -------- | ----- | ---------------------------- |
| 最大HP   | 100   | 強化 +10/段、★1つ +5         |

| 攻撃倍率 | ×1.0  | 強化 +5%/段、★1つ +3%        |
| 出撃時間 | 30秒  | 強化 +2秒/段（5段）          |
| 消耗品枠 | 3     | 強化 +1/段（最大5）          |

ラン中に枠をタップして使う。1回で消える。

| ---------- | --------------------------------------------------------------- |

| 時止め     | 3秒間、敵の行動を止める                                         |
| 油の大樽   | 画面内の全敵に油                                                |
| 雨乞いの符 | 画面内の全敵に濡れ                                              |
| 時の砂     | 出撃時間 +5秒                                                   |

| 幸運の硬貨 | 8秒間、会心率 +30%                                              |
| 回復薬     | HP +40                                                          |

- 消耗品枠は入れた中身（種類）を覚えていて、使い切ったら出撃前・結果画面で倉庫の同じものを自動で入れ直す。手で外すと覚えるのをやめる。消耗品枠は盤面ではなくプレイヤーについてくる（6.2）。

### 8.9 ランの終わり方と復活

- 終わり方: **時間切れ**／**力尽きた**（HP0）／**撤退**（一時停止メニューから）。どれでも、拾った戦利品と倒した敵のゴールドはすべて持ち帰る（ペナルティなし）。
- 力尽きたとき、1ランに1回だけ「広告を見て再開」（HP全回復＋出撃時間 +10秒）を選べる。挑戦・体験ランでは出ない。
- 到達周回 = 倒したボスの数 + 1。

### 8.10 レリック

普通のランとエンドレスで、**ボスを倒すたびに**、レリックが3つ（すべて違う種類。10種から抽選）出る。1つ選んで盤面のマスに貼ると、そのマスの装備に**そのランの間だけ**効く（ランが終わると消える）。

- 選んでいる間はランが止まる（時間も敵も進まない）。**8秒**で決めないと、レリックなしで続く。「いらない」で飛ばせる。
- 貼れるのは、装備があり、まだレリックのないマス。「攻撃」のレリックは攻撃装備のあるマスだけ。1マスに1つ。
- 効果はそのマスで鳴る装備ごとにかかる（重ねなら1つずつ）。加速の羽だけはマスの一番上で1回。

| レリック     | 貼れるマス | 効果                                                                                 |
| ------------ | ---------- | ------------------------------------------------------------------------------------ |
| 二度鳴りの鈴 | 攻撃       | 2回攻撃する                                                                          |
| 薙ぎ払いの紋 | 攻撃       | 交戦中の敵全員に当たる（単体・範囲の攻撃が薙ぎ払いになる。全体はそのまま）           |
| 貫きの矢じり | 攻撃       | 単体攻撃が後ろの敵2体まで貫く（貫通 +2）                                             |
| 巨人の拳     | 攻撃       | ダメージ ×2.5                                                                        |
| 会心の眼     | 攻撃       | 会心率 +50%                                                                          |
| 加速の羽     | 攻撃       | このあとに続く装備の連鎖数 +2                                                        |
| 吸血の牙     | 攻撃       | 与えたダメージの10%を回復                                                            |
| 金の爪       | 攻撃       | この装備で倒した敵は必ず装備を落とす（取り巻きは落とさない。エンドレスは戦利品なし） |
| 呼び戻しの笛 | どれでも   | ここまで届いた連鎖のあと、次の連鎖までの待ちが半分                                   |
| 守りの札     | どれでも   | ここが鳴るたびに防御 +5                                                              |

### 8.11 黄金ゴブリン

普通のランだけに出る、逃げる宝のゴブリン。

- 各周回の始めに **15%** で、群れの1つが黄金ゴブリン1体に替わる（1ランに1回まで）。
- 見た目はゴブリン。HP は同じ周回のゴブリンの **×7.5**。**攻撃しない**。勇者の前まで来てから **6秒**（時止めの間は数えない）で逃げる。
- 倒すと、装備を必ず **4個**（すべてレア以上、1つ目はエピック以上）と、ゴールドを地域の「1体のG」の10体分落とす。アクセサリーの出やすさはボスと同じ（6.3）。一網打尽には数えない。
- 「黄金ゴブリンだ！ 逃げる前に倒せ！」「黄金ゴブリンを倒した！」「黄金ゴブリンに逃げられた…」の帯が出る。

### 9.2 周回による強さの伸び

```
敵HP  = 基本HP × 地域のHP倍率 × 1.4^(周回−1) × 精鋭倍率（黄金ゴブリンは ×7.5）
敵攻撃 = 基本攻撃 × 地域の攻撃倍率 × 1.3^(周回−1) × 精鋭倍率
```

### 9.3 地域の開放と★

- **1回のランでボスを3体倒す（4周目に着く）**と、次の地域が開く。草原→洞窟→城壁→火山→氷河→魔王城。そのとき、クリアした地域の盤面ももらえる（6.1。魔王城の盤面は魔王を倒したとき）。
- **★**: 各地域で、最高到達周回が 4・7・11周目以上（＝3・6・10周目のボスを倒した）になるごとに★1つ。最大 6地域×3 = 18個。
- ★1つにつき、全地域で攻撃倍率 +3%・最大HP +5（永続）。
- 火山・氷河・魔王城を開放するたびに、強化「攻撃倍率」の上限が +10段、「最大HP」の上限が +5段。

### 9.4 エンドレス

- 魔王城で魔王（3周目のボス）を倒すと開放（＝魔王城の★1）。
- 魔王城の強さから始まり、周回の上限なし。雑魚は全地域の混成、ボスは毎周、強いボス9体から抽選。地域の効きにくい属性はない。
- **装備もゴールドも落とさない**（稼ぎ場にしないため）。黄金ゴブリンは出ず、アクセサリーも落ちない。盤面は選んだもの、アクセサリーは付けたものが働き、熟練は育ち、レリックも出る（1.2）。
- 記録は到達周回（同じなら合計ダメージ）の自己ベスト。
- 実績で大きなゴールド（5〜20周目で 3,000〜50,000G）。

### 9.5 2週替わりの挑戦（Challenge）

- 全員が**同じ地域・同じ乱数の種・同じ制限**で、自分の装備を並べて**合計ダメージ（スコア）**を競う。
- 盤面は**標準の盤面**だけ。倒しても連鎖数は続く。熟練はなし（必殺技は覚えていなくても全部出る。熟練のダメージもなし）。アクセサリー・レリック・黄金ゴブリンもなし。強化と★は使わない（勇者は初期の強さ: HP100・攻撃間隔1.5秒・攻撃倍率×1.0・30秒）。装備とゴールドは出ない。力尽きても再開なし。地域の記録・★・実績には数えない（出撃回数だけ数える）。倉庫があふれていても挑戦できる。
- 敵の強さは、その地域のふつうのランと同じ（9.1）。
- 4種類を14日ごとに順番に回す:

| 挑戦         | 地域 | 制限                                           |
| ------------ | ---- | ---------------------------------------------- |
| レアの意地   | 洞窟 | レア以下の装備だけ                             |
| 重ねない連鎖 | 城壁 | エピック以下、1マスに1つだけ（重ねない）       |
| 属性の試練   | 火山 | エピック以下、攻撃装備は炎・雷・氷・水・油だけ |
| 守りなし     | 氷河 | エピック以下、防御装備なし                     |

- 共通: アーティファクトは使えない。起点石はレアリティを問わない。制限は、重ねた下の装備まで見る。
- **挑戦用の配置**を、ふだんの盤面とは別に1つ持つ（いつも標準の盤面）。初めて開いたときは、ふだんの標準の盤面の配置（なければ自動配置。11.4）を写して、制限に合わせる。「ふだんの盤面から組む」で作り直せる。「制限に合わせる」は、制限に合わない装備を**同じ装備で制限内のレアリティ**のもの（一番上は出口の向きが近いもの）に入れ替える。代わりがなければ外し、下の装備が繰り上がる。「重ねない連鎖」では各マスの一番上だけ残す。最適化はしない（並べ方の腕で競うため）。
- 記録は期間ごとの自己ベスト。
- **公開状況**: 開始日（`CHALLENGE_START`）が未設定のため、通常のビルドでは「リリースから2週間後に開放」の予告と最初の挑戦の内容だけが出る。公開中の Web 試遊版は「今日の0時に始まった」扱いで開いているが、毎回その日の0時を開始日にするので、**常に第1回「レアの意地」（同じ乱数の種）**になる（コードからの推定）。

### 10.2 戦利品（ドロップ）

- 倒した敵（取り巻き以外）ごとにドロップ率で抽選。ボスは必ず **2個（レア以上確定）**、金ぴかの精鋭は必ず2個（レア以上確定）、黄金ゴブリンは必ず **4個（レア以上確定、1つ目はエピック以上）**。レリック「金の爪」のマスの装備で倒した敵は必ず落とす。
- 体験ランのあとの最初の自分のランでは、最初に倒した敵が必ず装備を1つ落とす（消耗品以外）。
- 落ちた装備1つごとに、アクセサリーも落ちることがある（6.3）。
- 抽選の順番:
  1. **アーティファクト**: 1回のドロップごとに 0.05%（ボス・金ぴか・黄金ゴブリンは 0.2%）× 地域の倍率（草原×1〜魔王城×10）。出たら、**持っていない種類**から等確率（そのランですでに出た種類も除く。全種類持っていれば、ふつうの戦利品の抽選に進む）。アーティファクトは1種類につき1つ。
  2. **種類**: 攻撃60%・防御15%・消耗品15%・起点石10%（レア以上確定のときに消耗品が出たら攻撃装備に置きかえ）。
  3. **レアリティ**（消耗品は常にコモン扱い）: 基本 コモン60%・レア30%・エピック9%・レジェンド1%。周回ごとに10%分、さらに地域の上乗せ分を、コモンからレア以上へ元の比率で移す（コモンは0%まで）。レア以上確定ならコモン0%。
  4. **装備**: そのレアリティで出る装備（系統の幅、10.3）から等確率。起点石は種類が増えても合わせて1つ分の重みで、半分がふつうの起点石、残りを11種類で等分。
  5. **出口**と**追加効果**を抽選。

### 10.3 レアリティと系統

- 表示名: コモン・レア・エピック・レジェンド。アーティファクトは別格（常にレジェンド扱い、虹色の縁）。
- 装備ごとに**出るレアリティの幅**がある（例: 剣はコモン〜エピック、大剣はレア〜レジェンド）。幅の上を超える合成は**系統の次の装備**になる（例: 剣のエピック3つ → 大剣のレジェンド）。系統は13章の表の「系統の次」。
- 起点石・槍・弓・双剣・疾風の羽は全レアリティで出る。

### 10.4 倉庫・売却・ロック・自動売却

- 倉庫の容量: 40（強化で +10×6段、最大100）。**装備中**（今選んでいる盤面に置いた装備（重ねた下の装備も）と消耗品枠）でないものを数える。ほかの盤面の配置で使っている装備は倉庫に数える。アクセサリーは数えない（6.3）。
- **容量を超えていると出撃できない**（戦利品は容量を超えても全部受け取る）。地域選択・配置画面から「あふれた分を売る」（装備中・ロック中・ほかの盤面で使用中・アーティファクト以外を、消耗品を後回しにして安い順に、ちょうど収まる数だけ）。
- 売値: コモン5G・レア20G・エピック60G・レジェンド200G・消耗品3G。
- **アーティファクトは売れない**（1種類につき1つ。詳細カードは「売れません」）。古いセーブで同じ種類を2つ以上持っているときだけ、余りの分を1000Gで売れる。
- 売り方: 詳細カードから1つ／「まとめて売る」（タップで選ぶ）／「一括売却」（コモン・レア以下・エピック以下・消耗品。✦付きを残す選択あり）。装備中・アーティファクトは一括では売らない。ほかの盤面で使っている装備は一括・まとめて売る・あふれた分・合成の相方から外れる（詳細カードからは確認のうえ売れる。6.2）。
- **ロック**: 詳細カードで切り替え。ロック中はどの方法でも売れず、合成の材料にもならない（消耗品はロック不可）。
- **自動売却**: 設定したレアリティ以下（オフ／コモン／レア以下／エピック以下、✦付きを残すか）を、ラン後に**今回の戦利品だけ**から売る。消耗品・アーティファクトは売らない。

- **ふち**: アクセサリーの枠（列ごと・行ごと。6.3）。
- **ルートの帯**: [全部][1] のチップで選ぶと、そのルートを太く描き、通るマスを縁取り、連鎖と同じ時間の流れで光の粒が流れる。「線を消す」でルート表示を消せる（設定として保存）。
- **推定ダメージ**（「約○○」）: 「全部」で合計、番号を選ぶと「約○○・○連鎖・コンボ○／技名」。アクセサリーでコンボ倍率が上がるときは「・コンボ ×○」が付く。中身はルート1本を**ふつうの敵1体**に撃ったときの期待値で、レアリティ・連鎖倍率・重ねの倍率・強化・同じ発火の中で先に付けた状態を後ろの装備が使うコンボ・追加効果・会心の期待値・必殺技（覚えていなくても入る）・起点石の種類・盤面の特徴・アクセサリーのコンボ倍率（会心ととどめの分は除く）を含む。毒は時間で与える分の半分、風で重ねた毒・毒爆はおおよそ。**含めないもの**: 範囲攻撃で巻き込む分、ボス専用の倍率、敵の得意・苦手、地域の効きにくい属性、熟練の Lv、レリック。
- **下**: 消耗品枠、「カカシ」、「出撃」。その下に倉庫の一覧（ほかの盤面で使っている装備には盤面の名前の印）。アクセサリーの枠を選んでいる間は、一覧がアクセサリー入れに替わる。
- **操作**:
  - 倉庫の一覧から装備を少し押さえて（または横へ動かして）盤面へドラッグ。空いたマスならそこに置き、装備のあるマスなら**上に重ねる**。置けないときは理由を出す（同じ装備だけ重ねられる／アーティファクトは重ねられない／1マスに○つまで／盤面の外／起点石は盤面に1つだけ）。
  - 盤面のマスをドラッグすると**重ね全体**が動き、行き先の重ねと入れ替わる。盤面の外へドラッグすると重ね全部が外れる。
  - 盤面のマスをタップすると**重ねの一覧**（上から順。各段の重ねの倍率、一番上は「矢印はこの装備」）。↑↓ で順番を入れ替え、「外す」で1つ外す（下の装備が上がる）。長押しで詳細カード（外す など）。
  - 倉庫の一覧の装備をタップすると詳細カード（装備は「置く」、消耗品は「枠に入れる」）。「置く」のあと、置きたいマスをタップ。
- **挑戦用の配置**も同じ画面（9.5）。盤面は標準に固定で、上は挑戦の名前と「制限に合わせる」。アクセサリーの枠は出ず、制限に合わない装備には「使えない」の印。

### 11.4 自動配置（画面のボタンはない）

- 持ち物から重ねる盤面を組む仕組み（`autoBoard`）。配置画面に自動で並べるボタンはない。使うのは、版1のセーブの移行（16.2）・初めて切り替えた盤面の最初の配置・挑戦用の配置のもと（ふだんの標準の配置がないとき）・ボット。
- ルール（わざと単純）:
  1. 起点石を1つ（出口の多い順、次にレアリティの高い順）。起点石を持っていなければ空の盤面（出撃は「起点がない」で止まる）。
  2. 同じ装備を盤面の深さまでまとめて「山」にする（良いものから）。山がマスより多いときは、防御の山は良いもの2つまでと、強い攻撃の山。
  3. 起点の出口の先から1マスずつ、**弱い山から順に**置く（強い山が連鎖の後ろに来る）。その先の空きマスへ出口が向いている装備を持つ山を優先し、その装備を一番上にする。つながるものがなければ残りでいちばん強い山を置いて線を終える。穴は空ける。
  4. 起点を置くマスを全部試して、推定ダメージがいちばん高いものを選ぶ。乱数は使わないので、同じ持ち物からはいつも同じ配置になる（ボットだけが乱数で揺らして探す）。

### 11.5 ラン画面

- 勇者は画面の中央寄り、敵は右から来る。HUD: HP・防御・残り時間（走っている間は薄く表示）・「地域 ○周目」の周回ゲージ・次の連鎖の予定（「○連鎖・○秒」）・消耗品枠。フィールドの下に盤面（鳴ったマスが光る）と、アクセサリーの枠・コンボ倍率。
- 演出（止めない）: ダメージ数字（連鎖数3・5・7・10で段階的に派手に）、属性ごとの攻撃エフェクト、コンボの文字、「一網打尽！」「ボス撃破！」「時間 +○」「よろめき！」「激昂！」「無効」、WARNING、「閃いた！ 技名」、NEW RECORD!、アーティファクト入手の帯、「アクセサリー！」、黄金ゴブリンの帯（8.11）。
- ボスを倒すとレリックを選ぶ画面（8.10）。この間だけランが止まる。
- 一時停止: 「再開」「撤退する」（撤退はここまでの戦利品を持ち帰って終わる）。ラン中に装備をタップするとゲームを止めて詳細カードを出す。
- ゲームスピード（設定、×0.5〜×3。検証用）: ルールの秒数は変えず、進む速さだけ変える。
- デバッグ機能（設定、開発中と試遊版だけ。初めは OFF）: ON のあいだ着せ替えの見た目を全部試せる。OFF に戻すと持っていない見た目は外れる。拠点に「0から遊ぶ（今のセーブは残る）」が出て、別のセーブで最初から遊べる。

### 11.7 そのほかの画面

- **倉庫**: 一覧（レアリティで絞り込み、並びはレア順／装備ごと）、まとめて売る、一括売却、自動売却、詳細カード（売る・ロック・合成）。ほかの盤面で使っている装備には盤面の名前の印。
- **鍛冶屋**: 「付け直し／合成」の切り替え。装備を選んで再抽選・指定・無料で再抽選、または合成（3つ以上そろっている装備に印）。
- **強化**: 6種の強化の現在値・次の値・値段・購入。
- **カカシ**（試し撃ち）: 今選んでいる盤面と、付けたアクセサリーで試す。熟練は今の Lv と覚えた技だけ（閃かず、熟練もたまらない）。地域の効きにくい属性はかからない。HP無限・攻撃しない的。「発火」で起点を手動で撃ち、総ダメージ・コンボ・持続（無防備）秒・防御値を見る。時間制限なし、記録には残らない。
- **ヘルプ**: 基本・盤面と重ね・ダメージの決まり方・伸ばすコツ・熟練と必殺技・短い連鎖と長い連鎖・アクセサリーとレリック・地域と敵・ご褒美とプレミアム・倉庫/鍛冶屋/合成。
- **設定**: 音量・振動・画面揺れ・光・ゲームスピード・言語・プレミアム（購入／購入を復元）・案内をもう一度。
- **挑戦**: 今回の挑戦の内容と制限・自己ベスト・挑戦用の配置（配置する／ふだんの盤面から組む）・「挑戦する」・「着せ替え」（拠点の勇者のタップと同じ画面）。
- **ランキング**: 挑戦／エンドレスの切り替え、上位100人と自分の順位（現在は「準備ができたら開きます」）。

### 11.8 チュートリアル

- 各画面を初めて開いたときに1回だけ、説明する場所を明るく残して吹き出しで案内（ラン中は戦闘を止める）。「スキップ」で以降の案内をすべて出さない。設定の「案内をもう一度」で見直せる。
- **体験ラン**（最初の出撃）: 標準の盤面（4×3）に、伝説級の装備（その装備で出せる一番上のレアリティ）を重ねた配置。起点は1つ（エピック、出口3）で、連鎖が全部のマスを蛇行する。前半に必殺技3つ（トライ・サンダー・クリムゾン・バースト・トリプル・スラッシュ）の並び、そのあと大斧の3つ重ねと竜牙の剣（アーティファクト。1つで3回鳴る）で締める。勇者は強化しきった姿（HP200・攻撃間隔1.0秒・攻撃倍率×2.0）。草原で20秒、延長なし・戦利品なし・記録や図鑑に残さない。熟練・レリック・アクセサリーは使わず、技は全部出る。
- そのあと「押してみよう」型の案内で、出撃 → 結果 → 配置へ導く。出撃2回以上で、倉庫・鍛冶屋・強化の案内を使える状態になったときだけ1つずつ出す。
- **配置画面の案内**（キー `board`）: 倉庫から盤面へドラッグ → 起点から矢印の向きに攻撃、起点は盤面に1つだけ → 同じ装備は重ねられる、上ほど強い → ふちはアクセサリーの枠 → 地域を抜けると新しい盤面、ここで切り替え → 「約」の数字。挑戦の配置では、アクセサリーと盤面の切り替えの案内は出ない。

## 15. 設計方針・意図（設計メモから）

- **並べる楽しさがゲームの中心**。自動化は手助けにとどめる: 配置画面に自動で並べるボタンはなく、自動配置（11.4）はセーブの移行・初めての盤面・ボットのためだけ。挑戦の「制限に合わせる」「ふだんの盤面から組む」は出撃できる形まで。
- **テンポを止めない**: 必殺技・閃き・実績・記録更新・WARNING などの演出でゲームを止めない（止まるのはヒットストップ程度）。止まるのはレリックを選ぶ間（最大8秒）だけ。
- **短い連鎖と長い連鎖のトレードオフ**: 長い連鎖は倍率で一撃が大きいが、待ちが長く、無防備・よろめきの危険がある。短い連鎖は回転が速く安全。
- **起点は盤面に1つ**。工夫の幅は、重ね（同じ装備を上へ）と、盤面の形・特徴、アクセサリーの列と行で出す。起点石の種類は今のまま。あとで「流れ方」だけを変える効果（属性なし・控えめな値・どの盤面でも役立つもの）を設計する。
- **属性ごとに役割**: 炎・雷・打撃は一撃が大きいコンボ、風（毒の重ねと毒爆）・光と闇（交互のコンボ・回復・敵の攻撃を遅く）はボス向けの別の役割。地域ごとの効きにくい属性（雷・風・光・闇にも1つずつ）と後半の地域の得意・苦手で、地域ごとに盤面と並べ方を変える理由を作る。地域の盤面は次の地域で役立つものにする。
- **奥の地域ほど一気に強く、そのぶん良い戦利品**。最初のランは弱い装備でボスまで届かないのが意図どおり（拾った装備で強くなってから挑む）。
- **強さは売らない**: 広告は見たいときだけ、課金はプレミアム（広告なしで同じご褒美）のみ。ランキングの報酬もゴールド・称号・見た目だけ。エンドレスは装備を落とさない。ランキングのある遊び方（挑戦・エンドレス）には黄金ゴブリンを出さない。挑戦は盤面のルールだけで、熟練・アクセサリー・レリックを使わない（みんな同じ条件）。
- **子ども向けのかっこよさ**: 名前は今の付け方（例: 水筒→水竜の瓶、状態は灼光・呪縛）を保ち、大きな改名はしない。属性ごとの派手な攻撃演出、勇者のオーラ、宝箱の演出。血の表現は使わない。有名なキャラクターに似た絵は作り直す。
- **言葉は分かりやすく**: 「ATB」→「攻撃間隔」、「段」→「連鎖／連鎖数」、装備を並べる場所は「盤面」、並べ方の記録は「配置」。
- **公正さと再現性**: 戦闘は決定的（固定ステップ・シード乱数・べき乗も掛け算の繰り返し）で、サーバーが再生して検証できる。ランの種類ごとのルールは `runFeatures` 1か所で決め、端末とサーバーが同じものを使う。言語を変えても結果は同じ。保存やサーバーには訳した文を入れない。
- **バランスの調整方法**: 参考配置のシミュレーション（`npm run sim`）と、自動プレイのボット（`npm run playtest`）で地域の開放までの出撃回数などを見て決めている。敵の強さは地域の HP の倍率で合わせている（16.3）。

### 16.2 既知の制約

- セーブは端末内だけ。**端末やブラウザを変えると持ち物も進行も引き継げない**（サーバーから戻す仕組みはない。装飾品も同じ）。
- セーブは版2で、キー `bp30.save.v2` に書く（デバッグの「0から遊ぶ」は `bp30.save.v2.fresh`）。版1のキー（`bp30.save.v1`）には書かない。版2がなければ版1を読んで移す（`migrateV1`）: 版1に重ねる盤面の配置があればそれを使い、なければ持ち物から自動配置で標準の盤面を作る。版1の自由に並べる配置は捨てる（装備は倉庫に残る）。版1の強化「バックパック拡張」に払ったゴールド（最大2,100G）を返す。見つけていた必殺技は覚えた技にする。挑戦用の配置は次に開いたときに作り直す。記録・実績・★・開放・見た目は残す。移行で倉庫があふれても何も売らない（出撃前に「あふれた分を売る」）。
- 公開を戻すと、古いコードは版1のキー（移行した時点のまま）を読むので、そのまま遊べる。そのあとでもう一度出すと版2が優先し、戻していた間に古いコードで進めた分は引き継がない。
- Android のアプリ内では Web の共有が使えないことがある（ネイティブ版では共有プラグインに切り替える予定）。
- 勇者の被弾モーションは未登録。
- 必殺技の本体は、撃った瞬間の敵の位置へ向かう。登場直後で前へ歩いているボスに撃つと、届くまでの間にボスが進み、少し後ろに落ちる（連鎖で技が出るのは戦っている敵なので、ふだんは起きない）。
- 着弾の演出のうち、トリプル・スラッシュ（三角形の線と輪）とクリムゾン・バースト・トライ・サンダーの着弾はコードで描いた形のまま（氷・竜巻・ヴェノムは本体の絵を見せ場にした）。
- レリック・アクセサリーの印は、絵ができるまで1文字（例: 拳・揃）で出している。

### 16.3 バランス上の課題（設計メモより）

- 自動プレイのボット（30人×600ラン、種 9000+p）での地域開放までのラン数の中央値: 洞窟20・城壁43・火山161・氷河219・魔王城415。魔王城に届いたボットは30人中28人。ボットは技の並びをほとんど作らないので、技を組むプレイヤーはボットより少し強い。
- 火山（HP×26）・氷河（HP×27）は「奥の地域ほど強い」の下限ぎりぎり。奥の3地域は HP がほぼ同じで、違いは主に攻撃力と耐性。
- エンドレスは魔王城と同じ HP×38。ボットは3000ランでも魔王を倒せないので、エンドレスの開放のペースは比べられていない。
- 序盤: ボットは1〜5ラン目に倒れずに1周目で時間切れになる。草原の強さひとつでは序盤の手応えと開放のペースの両方は合わないので、開放のペースを優先した。
- 挑戦は地域の強さをそのまま使い、盤面のルールだけ（熟練・アクセサリー・レリックなし、初期の勇者）で戦うので、厳しめ。
- 別に相談する課題（設計書の範囲外）: 起点石の「流れ方」の効果、レリックが弱め、ランが長め、物理の型が強め。
- 起点石の種類、風・光・闇の数値、アクセサリーの値などは（仮）の値。
- 最初の自分のラン（初期装備・草原）は最初のボスまで届かないのが普通。
