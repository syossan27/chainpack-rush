# 広告・課金の準備（本番へつなぐまで）

いまはテスト用のモックで動いている（`src/platform/monetization.ts`）。報酬つき広告は3秒の「テスト広告」画面、プレミアムはすぐ購入できたことにする。本物につなぐときは `setMonetizationProvider()` で差し替える。

## ゲームの中の置き場所（実装済み）

| 置き場所 | ご褒美 | 回数 |
| --- | --- | --- |
| 結果画面「戦利品を2倍にする」 | 今回と同じ装備・同じレアリティをもう1セット（追加効果と向きは新しく、アーティファクトは除く） | 1日3回（1回の結果で1回） |
| 鍛冶屋「無料で再抽選」 | 向きの再抽選を無料で（料金も回数も増えない） | 1日3回 |
| 力尽きたとき「再開」 | HP全回復＋10秒 | 1ランに1回 |
| プレミアム（480円・買い切り） | 上のご褒美を広告なしで受け取れる（回数は同じ） | ― |

回数は `MONETIZE`（`src/config/balance.ts`）で変えられる。

## そちらでやること（アカウント・ストア）

1. Apple Developer Program に登録（年会費）／Google Play の開発者登録（初回のみ）。
2. AdMob に登録し、iOS・Android それぞれでアプリを作成。報酬つき広告の広告ユニットを作る（「戦利品」「鍛冶屋」「再開」の3つに分けると効果が見やすい）。アプリID と広告ユニットID を教えてほしい。
3. AdMob のアプリ設定で、子ども向けの扱い（対象年齢の設定・好みに合わせない広告）を選ぶ。ストアは一般カテゴリ（対象年齢9歳以上など）で出す想定。
4. App Store Connect／Google Play Console で、買い切り（非消耗型）の課金アイテムを1つ作る（例: ID `premium`、480円）。有料アプリの契約・税金・振込口座の設定も必要。
5. プライバシーポリシーのページ（URL）を用意し、ストアのプライバシー情報・データセーフティを記入する。AdMob の `app-ads.txt` を置くサイトも必要。
6. 実機でのテスト: iOS は Xcode、Android は Android Studio でビルドし、テスト広告とテスト購入（サンドボックス）で確かめる。
